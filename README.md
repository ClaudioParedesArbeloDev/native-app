## 🇪🇸 Español

### Qué es

Punto de partida de una app móvil para **Code & Lens** con **Expo** y **Expo Router** (navegación basada en archivos). Incluye componentes con tema claro/oscuro (`ThemedView`, `ThemedCard`) y pantalla inicial con la marca.

> 🚧 En desarrollo.

### Cómo correrlo

```bash
git clone https://github.com/ClaudioParedesArbeloDev/native-app.git
cd native-app
npm install
npx expo start      # abrir con Expo Go, emulador Android/iOS o web
```

---

## 🇬🇧 English

### What it is

Starting point for a **Code & Lens** mobile app built with **Expo** and **Expo Router** (file-based navigation). Includes light/dark themed components (`ThemedView`, `ThemedCard`) and a branded home screen.

> 🚧 Work in progress.

### Running it

```bash
npm install
npx expo start
```
